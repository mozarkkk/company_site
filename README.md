# Company Site

Репозиторий содержит исходный код для веб-сайта компании. Проект представляет собой статическую страницу с адаптивной версткой.

## Структура проекта

```
company_site/
├── assets/
│   └── team.svg
├── index.html
└── style.css
```

* **index.html** — основная HTML-разметка страницы.
* **style.css** — стили оформления и адаптивная сетка.
* **assets/team.svg** — векторная иллюстрация для секции команды.

## Технологии

* HTML5
* CSS3
* SVG
